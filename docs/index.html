Features

The familiar AltStore workflow, brought up to date.

AltDaemon Modern preserves AltStore’s existing XPC protocol while repairing the daemon’s provisioning, transport, and app-installation paths.

Modern anisette provisioning

Anisette v3 replaces the obsolete private AuthKit generator and persists a stable identifier with its matching provisioning state.

Provider failover

Automatically try three HTTPS SideStore endpoints, remember the last working provider, or configure a trusted self-hosted server.

AltStore Classic compatibility

A scoped compatibility module updates Classic 2.2.1’s obsolete authentication identity and handles transient Apple service failures.

iOS 26 installation

Use InstallCoordination when the older LaunchServices installer is unavailable, with the runtime options expected by the new API.

Smoother self-refresh

Stage AltStore’s self-refresh and allow App Intents to return before replacement, improving Shortcuts refresh handoff.

Bounded, serialized requests

Swift actor serialization, a repaired XPC read queue, and bounded retries improve daemon stability while sensitive authentication values stay out of logs.

Usage

Install the package. Refresh from AltStore.

AltDaemon Modern is intended for compatible rootless jailbreaks and AltStore Classic. The repository guide explains the device-specific AltStore setup.

Compatibility

Made for standard rootless environments.

The minimum deployment target is iOS 15.0. A compatible jailbreak, AltStore installation, and Apple-account workflow are required.

Dopamine rootless

The primary target is Dopamine’s standard rootless environment under /var/jb. RootHide is currently unsupported.

iOS compatibility

The current release supports iOS 26’s installation path. Jailbreak and AltStore compatibility still depend on the device and iOS version.

Provider trust

The anisette provider receives the random identifier and ADI provisioning blob. A trusted self-hosted server is recommended when possible.

Open source

Daemon changes and reproducible build scripts are available on GitHub under AGPLv3, with upstream and third-party notices preserved.

An independent fork. Apple-account authentication remains between AltStore/AltSign and Apple; AltDaemon does not receive the Apple ID password.
